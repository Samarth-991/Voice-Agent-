About

DeepAgent Voice is a real-time voice assistant. Speech detection, transcription and synthesis run as open models on this machine's GPU; the reply comes from a LangChain Deep Agent on Azure OpenAI that can search and read the web, plan multi-step requests, and hand in-depth questions to a research subagent. The conversation UI is adapted from Hugging Face's speech-to-speech demo.

About LangChain Deep Agents

The pipeline

  1. You speak
  2. VAD detects speech silero-vad
  3. STT transcribes it distil-whisper large-v3
  4. AGENT searches, plans and composes the reply Deep Agent · Azure OpenAI
  5. TTS speaks it back hexgrad/Kokoro-82M
  6. The orb replies
